## EJ-04-02-03 — Marko crea funciones para sus comandos más frecuentes

> [!info] Situación
> Marko repite muchas veces cadenas largas (`git status`, `git log --oneline -5`, `git add . && git commit && git push`). Quiere **atajos personales** en su terminal.

- **🎯 Objetivo real:** crear **funciones** en el perfil de la terminal para lanzar flujos personales rápidos (más allá de los alias de Git).
- **🧩 Problema que resuelve:** repetir cadenas largas cansa y ralentiza.

---

## 📚 Fundamento

> [!info] Antes de empezar: alias de Git vs funciones de la terminal
> - Un **alias de Git** (EJ-01-03-02) abrevia **un** subcomando (`git st` = `git status`).
> - Una **función de terminal** puede **encadenar varios** comandos (`git add` + `commit` + `push` en uno). Se guarda en el **perfil** de tu terminal, que se carga al abrirla.

> [!abstract] Idea clave: cada terminal tiene su "perfil"
> - En **PowerShell**, el perfil es el archivo **`$PROFILE`**.
> - En **Git Bash / Linux**, es **`~/.bashrc`**.
> Añades ahí tus funciones y quedan disponibles cada vez que abras la terminal.

> [!example] Vocabulario de esta práctica
> - **Perfil de terminal:** archivo que se ejecuta al abrir la terminal (`$PROFILE` / `~/.bashrc`).
> - **Función:** atajo que agrupa varios comandos.

---

## 🛠️ Procedimiento
Elige tu terminal. La idea es la misma; cambia dónde se escribe.

> [!example] Paso 1 — Abre tu perfil
> *🐧 Git Bash / Linux*
> ```bash
> nano ~/.bashrc
> ```
> *🪟 PowerShell*
> ```powershell
> notepad $PROFILE
> ```
> *(Si PowerShell dice que no existe, acepta crearlo.)*

> [!example] Paso 2 — Añade tus funciones
> *🐧 Git Bash / Linux* (al final de `~/.bashrc`)
> ```bash
> gst() { git status; }
> gl5() { git log --oneline -5; }
> gpush() { git add .; git commit -m "$1"; git push; }
> ```
> *🪟 PowerShell* (en `$PROFILE`)
> ```powershell
> function gst { git status }
> function gl5 { git log --oneline -5 }
> function gpush { git add .; git commit -m $args[0]; git push }
> ```

> [!example] Paso 3 — Recarga el perfil
> *🐧 Git Bash / Linux*
> ```bash
> source ~/.bashrc
> ```
> *🪟 PowerShell*
> ```powershell
> . $PROFILE
> ```

> [!example] Paso 4 — Pruébalas
> ```
> gst
> gl5
> gpush "EJ-04-02-03 · Configuradas funciones de terminal"
> ```

## 🚩 Errores y verificación

> [!warning] Errores típicos (evítalos)
> | Error | Qué pasa | Cómo evitarlo |
> | :--- | :--- | :--- |
> | Editas el perfil pero no lo recargas | Las funciones no aparecen | Recarga con `source`/`. $PROFILE` o abre una terminal nueva. |
> | Mezclas la sintaxis de las dos terminales | Da error | Usa la sintaxis de la terminal que estés usando. |

> [!success] ✅ Verificación: ¿está bien hecho?
> - Las funciones (`gst`, `gl5`, `gpush`) funcionan al abrir una terminal nueva.
