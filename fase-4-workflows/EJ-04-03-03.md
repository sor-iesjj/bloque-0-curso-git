## EJ-04-03-03 — Marko usa `git worktree` para varias ramas en paralelo

> [!info] Situación
> Marko trabaja en `feature/manual-vpn`, pero Lucía le pide URGENTE revisar `hotfix/cockpit`. No quiere hacer `stash` + `switch` + volver: quiere **las dos ramas abiertas a la vez**, en carpetas distintas.

- **🎯 Objetivo real:** usar `git worktree` para tener **varias ramas** desplegadas al mismo tiempo, cada una en su carpeta.
- **🧩 Problema que resuelve:** sin worktree, Marko salta entre ramas con `stash` continuo, o clona el repo varias veces.

---

## 📚 Fundamento

> [!info] Antes de empezar: dos escritorios, un mismo proyecto
> Normalmente una rama "ocupa" tu carpeta de trabajo y para ver otra tienes que cambiar. **`git worktree`** te deja tener **una segunda carpeta** con **otra rama** desplegada, a la vez. Las dos comparten el **mismo repositorio** (`.git`), así que no ocupa el doble en disco.

> [!abstract] Idea clave: ideal para urgencias
> Es perfecto cuando estás a medias de algo y entra una urgencia: abres el hotfix en **otra carpeta**, lo resuelves, y tu trabajo original **sigue intacto** en la suya. Sin stash, sin saltos.

> [!example] Vocabulario de esta práctica
> - **`git worktree add <carpeta> <rama>`:** despliega esa rama en una carpeta nueva.
> - **`git worktree remove <carpeta>`:** la retira cuando ya no la necesitas.
> - **Regla:** no puedes tener la **misma** rama en dos worktrees.

---

## 🛠️ Procedimiento
Desde `Manuales/` (estando en `feature/manual-vpn`).

> [!example] Paso 1 — Abre el hotfix en una carpeta hermana
> *🐧 Git Bash / Linux*
> ```bash
> git worktree add ../Manuales-hotfix hotfix/cockpit
> ```
> *🪟 PowerShell*
> ```powershell
> git worktree add ..\Manuales-hotfix hotfix/cockpit
> ```

> [!example] Paso 2 — Ahora tienes DOS carpetas de trabajo
> - `Manuales/` con `feature/manual-vpn`.
> - `Manuales-hotfix/` con `hotfix/cockpit`.
> Puedes trabajar en ambas en paralelo.

> [!example] Paso 3 — Cuando termines el hotfix, retira el worktree
> *🐧 Git Bash / Linux*
> ```bash
> git worktree remove ../Manuales-hotfix
> ```
> *🪟 PowerShell*
> ```powershell
> git worktree remove ..\Manuales-hotfix
> ```

## 🚩 Errores y verificación

> [!warning] Errores típicos (evítalos)
> | Error | Qué pasa | Cómo evitarlo |
> | :--- | :--- | :--- |
> | Intentas abrir la misma rama en dos worktrees | Git lo rechaza | Cada worktree usa una rama distinta. |
> | Borras la carpeta a mano | Quedan referencias sueltas | Retírala con `git worktree remove`. |

> [!success] ✅ Verificación: ¿está bien hecho?
> - Existen dos carpetas con dos ramas distintas desplegadas a la vez.
