## EJ-03-03-03 — Marko usa CODEOWNERS

> [!abstract] Ficha de la práctica
> ### 📌 `F3.3.3` — Marko usa CODEOWNERS
> - **Fase 3** (Colaboración) · **Nivel 3** (Sobresaliente)
> - **🎬 Playlist:** `Curso Git — Fase 3`
> - **📹 Nombre del vídeo:** `F3.3.3 · Marko usa CODEOWNERS`

> [!info] Situación
> El repo crece. Hay manuales de seguridad que **solo** debería revisar Lucía (responsable de seguridad). Marko define **propietarios automáticos** por área.

- **🎯 Objetivo real:** configurar `.github/CODEOWNERS` para asignar revisores automáticos según el archivo que se modifique.
- **🧩 Problema que resuelve:** sin CODEOWNERS, hay que asignar revisores a mano en cada PR, y se olvida.

---

## 📚 Fundamento

> [!info] Antes de empezar: "quién es dueño de qué"
> `CODEOWNERS` es un archivo donde dices **qué persona debe revisar qué carpetas**. A partir de ahí, cuando alguien abre un PR que toca esa carpeta, GitHub **asigna automáticamente** al revisor correspondiente. Ideal para que "seguridad" siempre pase por quien sabe de seguridad.

> [!abstract] Idea clave: automatizar la responsabilidad
> En vez de recordar "esto que lo mire Lucía", lo **escribes una vez** en CODEOWNERS y GitHub se encarga siempre. Combinado con la protección de rama ("Require review from Code Owners"), se vuelve **obligatorio**.

> [!example] Vocabulario de esta práctica
> - **CODEOWNERS:** archivo que asigna revisores por carpeta/patrón.
> - **`@usuario`:** el revisor asignado.
> - **`*`:** patrón que significa "todo".

## 🛠️ Procedimiento
Trabaja dentro de `Manuales/`.

> [!example] Paso 0 — Prepárate y empieza a grabar
> 1. **Léete el ejercicio entero** antes de tocar nada, para no perderte a mitad del vídeo.
> 2. **Ten a mano OBS** y una pestaña del navegador con tu **Teams** o tu correo `@alu.edu.gva.es` (para presentarte).
> 3. **Arranca OBS** y pulsa **"Iniciar grabación"**. A partir de aquí, **todo queda grabado**.
> 4. **Preséntate** (mira la caja de grabación de arriba): di tu nombre, muestra tu identidad y di qué vas a hacer.

> [!example] Paso 1 — Crea el archivo `.github/CODEOWNERS`
> *🐧 Git Bash / Linux*
> ```bash
> mkdir -p .github
> touch .github/CODEOWNERS
> ```
> *🪟 PowerShell*
> ```powershell
> New-Item .github -ItemType Directory -Force
> New-Item .github\CODEOWNERS -ItemType File
> ```

> [!example] Paso 2 — Define los propietarios por área
> Edita `.github/CODEOWNERS`:
> ```
> # Por defecto, Marko revisa todo
> *  @marko-boochan
>
> # Seguridad: Lucía obligatoria
> 05_seguridad/  @lucia-boochan
>
> # Active Directory: Carlos + Lucía
> 02_active_directory/  @carlos-boochan @lucia-boochan
> ```

> [!example] Paso 3 — Súbelo
> ```
> git add .github/CODEOWNERS
> git commit -m "EJ-03-03-03 · Definidos CODEOWNERS por área"
> git push
> ```

> [!example] Paso 4 — Compruébalo
> Abre un PR que toque `05_seguridad/`: GitHub asigna automáticamente a **@lucia-boochan** como revisora.

> [!example] Paso 5 — Cierra la grabación y súbela
> 1. **Detén la grabación** en OBS y localiza el archivo del vídeo.
> 2. **Súbelo a YouTube**, a tu playlist **`Curso Git — Fase 3`**, como **"No listado"**.
> 3. Nombra el vídeo **`F3.3.3 · Marko usa CODEOWNERS`**.
> 4. En la **descripción**, añade los **timestamps**: `00:00 Presentación` y **uno por cada paso**.

## 🚩 Errores y verificación

> [!warning] Errores típicos (evítalos)
> | Error | Qué pasa | Cómo evitarlo |
> | :--- | :--- | :--- |
> | Usernames inventados | No se asigna a nadie real | En clase, usa los usernames reales de tus compañeros. |
> | Colocas el archivo fuera de `.github/` | GitHub no lo reconoce | Debe estar en `.github/CODEOWNERS`. |
