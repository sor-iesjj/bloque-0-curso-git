## EJ-03-02-04 — Marko corrige un Issue desde una rama y lo cierra desde un PR

> [!abstract] Ficha de la práctica
> ### 📌 `B0.G.3.2.4` — Marko corrige un Issue desde una rama y lo cierra desde un PR
> - **Fase 3** (Colaboración) · **Nivel 2** (Notable)
> - **🎬 Playlist:** `B0_Curso_Git`
> - **📹 Nombre del vídeo:** `B0.G.3.2.4 · Marko corrige un Issue desde una rama y lo cierra desde un PR`

> [!info] Situación
> El Issue del ejercicio anterior hay que arreglarlo. Marko crea una rama, corrige el error y abre un PR **enlazado al Issue** para que se cierre solo al fusionar.

- **🎯 Objetivo real:** conectar Issues con PR usando palabras clave (`Closes #N`) para cerrarlos automáticamente al fusionar.
- **🧩 Problema que resuelve:** sin enlazar, hay que cerrar el Issue a mano y se pierde la trazabilidad "problema → solución".

---

## 📚 Fundamento

> [!info] Antes de empezar: el ciclo completo bug → fix
> El flujo profesional para un bug es: **Issue** (lo registras) → **rama** (lo arreglas aparte) → **PR** (propones el arreglo) → al **fusionar**, el Issue **se cierra**. GitHub conecta el PR con el Issue si escribes una palabra clave.

> [!abstract] Idea clave: `Closes #N` hace la magia
> Si en el commit o en la descripción del PR escribes **`Closes #1`** (o `Fixes #1`, `Resolves #1`), al fusionar el PR el **Issue #1 se cierra solo** y queda enlazado. Trazabilidad automática.

> [!example] Vocabulario de esta práctica
> - **`Closes #N` / `Fixes #N` / `Resolves #N`:** palabras clave que cierran el Issue al fusionar.
> - **Rama `bugfix/…`:** convención para ramas de corrección.

## 🚩 Errores y verificación

> [!warning] Errores típicos (evítalos)
> | Error | Qué pasa | Cómo evitarlo |
> | :--- | :--- | :--- |
> | Escribes el número mal (`Closes 1`) | No enlaza | Debe llevar `#`: `Closes #1`. |
> | Cierras el Issue a mano antes | Pierdes la conexión con el PR | Deja que lo cierre el PR con la palabra clave. |

> [!success] ✅ Verificación: ¿está bien hecho?
> - El Issue #1 aparece **cerrado**.
> - En el Issue se ve la **referencia al PR** que lo cerró.
