## EJ-03-03-05 — Marko crea una plantilla de Pull Request

> [!abstract] Ficha de la práctica
> ### 📌 `F3.3.5` — Marko crea una plantilla de Pull Request
> - **Fase 3** (Colaboración) · **Nivel 3** (Sobresaliente)
> - **🎬 Playlist:** `Curso Git — Fase 3`
> - **📹 Nombre del vídeo:** `F3.3.5 · Marko crea una plantilla de Pull Request`

> [!info] Situación
> Lucía: *"Todos los PR deben llevar la misma información: qué cambia, por qué, cómo probar, capturas si aplica. Crea una plantilla."*

- **🎯 Objetivo real:** configurar `.github/pull_request_template.md` para que GitHub **rellene automáticamente** la descripción de cada PR.
- **🧩 Problema que resuelve:** sin plantilla, cada PR se describe como uno quiere y la calidad varía.

---

## 📚 Fundamento

> [!info] Antes de empezar: un formulario para cada PR
> Una **plantilla de PR** es un archivo con la estructura que quieres que tengan **todas** las descripciones de PR. GitHub la carga sola cada vez que se abre un PR nuevo, así todos rellenan lo mismo: qué cambia, por qué, cómo probar, checklist.

> [!abstract] Idea clave: la calidad se estandariza escribiéndola una vez
> En vez de recordar a cada uno qué poner, lo dejas escrito en la plantilla. El formato deja de depender de la memoria o las ganas de cada persona.

> [!example] Vocabulario de esta práctica
> - **`pull_request_template.md`:** archivo de plantilla de PR (en `.github/`).
> - **`<!-- comentario -->`:** texto de ayuda que **no** se muestra al renderizar.
> - **Checklist `- [ ]`:** casillas que el autor marca antes de pedir revisión.

## 🛠️ Procedimiento
Trabaja dentro de `Manuales/`.

> [!example] Paso 0 — Prepárate y empieza a grabar
> 1. **Léete el ejercicio entero** antes de tocar nada, para no perderte a mitad del vídeo.
> 2. **Ten a mano OBS** y una pestaña del navegador con tu **Teams** o tu correo `@alu.edu.gva.es` (para presentarte).
> 3. **Arranca OBS** y pulsa **"Iniciar grabación"**. A partir de aquí, **todo queda grabado**.
> 4. **Preséntate** (mira la caja de grabación de arriba): di tu nombre, muestra tu identidad y di qué vas a hacer.

> [!example] Paso 1 — Crea el archivo de plantilla
> *🐧 Git Bash / Linux*
> ```bash
> mkdir -p .github
> touch .github/pull_request_template.md
> ```
> *🪟 PowerShell*
> ```powershell
> New-Item .github -ItemType Directory -Force
> New-Item .github\pull_request_template.md -ItemType File
> ```

> [!example] Paso 2 — Escribe la estructura
> Edita `.github/pull_request_template.md`:
> ```
> ## Qué cambia
> <!-- Resumen de los cambios -->
>
> ## Por qué
> <!-- Motivación: issue, petición de Lucía, audit, etc. -->
>
> ## Cómo probar
> <!-- Pasos para verificar manualmente -->
>
> ## Checklist
> - [ ] Manual actualizado en la bóveda
> - [ ] Vídeo grabado (si aplica)
> - [ ] CODEOWNERS asignados
> - [ ] Sin secretos en el diff
>
> ## Captura (opcional)
> <!-- Adjuntar imágenes -->
> ```

> [!example] Paso 3 — Súbelo
> ```
> git add .github/pull_request_template.md
> git commit -m "EJ-03-03-05 · Plantilla de Pull Request"
> git push
> ```

> [!example] Paso 4 — Compruébalo
> Abre un PR nuevo: la descripción viene **pre-rellenada** con la plantilla.

> [!example] Paso 5 — Cierra la grabación y súbela
> 1. **Detén la grabación** en OBS y localiza el archivo del vídeo.

## 🚩 Errores y verificación

> [!warning] Errores típicos (evítalos)
> | Error | Qué pasa | Cómo evitarlo |
> | :--- | :--- | :--- |
> | Nombre o carpeta incorrectos | GitHub no la usa | Debe ser `.github/pull_request_template.md`. |
> | Dejas los `<!-- comentarios -->` sin rellenar | El PR queda vacío de contenido | Sustitúyelos por el texto real al abrir el PR. |

> [!success] ✅ Verificación: ¿está bien hecho?
> - Al abrir un PR nuevo, la descripción aparece **pre-rellenada** con la plantilla.
