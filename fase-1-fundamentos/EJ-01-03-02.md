> [!info] Situación
> Marko lleva una semana tecleando `git status` 50 veces al día. Carlos le dice: *"Yo escribo `git st`. Tú también puedes."*

- **🎯 Objetivo real:** configurar **alias** de Git globales para acelerar el trabajo diario.
- **🧩 Problema que resuelve:** repetir comandos largos cansa y ralentiza. Un técnico pasa horas en la terminal: cada segundo cuenta.

---

## 📚 Fundamento

> [!info] Antes de empezar: un alias es un apodo para un comando
> Un **alias** es un nombre corto que tú inventas para un comando largo. Cuando defines `st` como alias de `status`, escribir `git st` es exactamente lo mismo que escribir `git status`, pero más rápido.

> [!abstract] Idea clave: personaliza tu herramienta, sin cambiarla
> Los alias son **tuyos** (se guardan en tu configuración global). No cambian Git ni afectan a tus compañeros: cada técnico puede tener los suyos. Es como poner accesos directos en tu escritorio.

> [!example] Vocabulario de esta práctica
> - **Alias:** apodo corto para un comando.
> - **`--global`:** el alias vale para todos tus repositorios.
> - **Comillas:** si el valor del alias lleva espacios, va entre comillas.

## 🛠️ Procedimiento
Los comandos `git config` son idénticos en las dos terminales.

> [!example] Paso 0 — Prepárate y empieza a grabar
> 1. **Léete el ejercicio entero** antes de tocar nada, para no perderte a mitad del vídeo.
> 2. **Ten a mano OBS** y una pestaña del navegador con tu **Teams** o tu correo `@alu.edu.gva.es` (para presentarte).
> 3. **Arranca OBS** y pulsa **"Iniciar grabación"**. A partir de aquí, **todo queda grabado**.
> 4. **Preséntate** (mira la caja de grabación de arriba): di tu nombre, muestra tu identidad y di qué vas a hacer.

> [!example] Paso 1 — Crea 5 alias útiles
> ```
> git config --global alias.st status
> git config --global alias.co checkout
> git config --global alias.br branch
> git config --global alias.lg "log --oneline --graph --all"
> git config --global alias.unstage "restore --staged"
> ```

> [!example] Paso 2 — Pruébalos
> ```
> git st
> git lg
> ```

> [!example] Paso 3 — Mira todos tus alias
> ```
> git config --global --get-regexp alias
> ```

> [!example] Paso 4 — Cierra la grabación y súbela
> 1. **Detén la grabación** en OBS y localiza el archivo del vídeo.
> 2. **Súbelo a YouTube**, a tu playlist **`Curso Git — Fase 1`**, como **"No listado"**.
> 3. Nombra el vídeo **`F1.3.2 · Marko crea alias para no escribir tanto`**.
> 4. En la **descripción**, añade los **timestamps**: `00:00 Presentación` y **uno por cada paso**.

## 🚩 Errores y verificación

> [!warning] Errores típicos (evítalos)
> | Error | Qué pasa | Cómo evitarlo |
> | :--- | :--- | :--- |
> | Alias con espacios sin comillas | Da error o guarda mal | Pon el valor entre comillas: `alias.lg "log --oneline"`. |
> | Esperas que tus alias los tenga Carlos | No los verá | Los alias son personales, viven en TU configuración. |

> [!success] ✅ Verificación: ¿está bien hecho?
> - `git st` funciona igual que `git status`.
> - El manual de configuración existe en tu bóveda.
