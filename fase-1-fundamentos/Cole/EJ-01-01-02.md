## EJ-01-01-02 — Cole: comprobar tu identidad de Git

> [!important] Esta guía es autónoma para el contexto Cole
> Comprueba la configuración en el ordenador de Cole. No depende de lo que hayas configurado en Cole ni cambia ninguna preferencia.

> [!danger] No configures la identidad ficticia de Marko
> La identidad global debe ser la tuya. Esta ficha solo consulta valores; **no ejecutes aquí comandos `git config --global` que escriban datos**. Si está vacía o no coincide, no la cambies aquí: esta guía es de consulta. El EJ-01-01-00 configura la identidad real localmente en cada repositorio antes del primer commit.

> [!example] Consulta la identidad global
> Ejecuta las dos consultas:
> ```bash
> git config --global user.name
> git config --global user.email
> ```
> **Línea por línea:** el primer comando consulta el nombre global de Git; el segundo consulta el correo global. Ambos son solo lectura.
>
> Anota lo que aparece. Si no coincide con tus datos o está vacío, no lo cambies aquí: EJ-01-01-00 establece después la identidad local antes de crear commits. No uses `Marko Boochan` ni `marko@boochan.local`. Anota ambos resultados en la entrada del `EJ-01-01-00` de Cole.

> [!info] Entrega
> No se entrega esta comprobación por separado. La guía del `EJ-01-01-00` de Cole crea su propia bóveda y bitácora desde cero.
