> [!info] Situación
> Lucía le pide a Marko: *"En cuanto hagas un cambio crítico, quiero que GitHub pueda comprobar que el commit lleva una firma hecha con la clave de firma que tenemos registrada."*

- **🎯 Objetivo real:** configurar la **firma de commits con clave SSH** (más simple que GPG en Windows). GitHub puede mostrar **"Verified"** cuando reconoce la clave de firma y la asocia correctamente a la identidad del commit.
- **🧩 Problema que resuelve:** sin firma, cualquiera puede commitear poniendo `user.name = Marko Boochan` desde otro PC. La firma permite comprobar que el commit se creó con la clave privada correspondiente a una clave pública registrada. No demuestra por sí sola quién usó esa clave: si alguien comparte la clave privada o esta queda expuesta, otra persona podría usarla.

## 📚 Fundamento

> [!info] Antes de empezar: nombre ≠ firma
> En EJ-01-01-02 consultaste tu nombre y correo; la identidad local se configuró al crear cada repositorio. Eso identifica el commit con una etiqueta, pero cualquiera podría escribir ese texto. La firma permite comprobar que se utilizó la clave privada correspondiente a una clave pública registrada. No demuestra quién pulsó las teclas si la clave privada se comparte o queda expuesta.

> [!abstract] Idea clave: la misma clave SSH sirve para dos cosas
> Una clave SSH puede utilizarse para autenticación y para firma, pero GitHub debe tenerla registrada para cada uso. Aquí configurarás la firma solo en el repositorio `Manuales` de este recorrido; así Cole y Casa conservan configuración separada. La firma permite comprobar el uso de la clave privada correspondiente; no identifica por sí sola a la persona que la usó si la clave se comparte o queda expuesta.

> [!example] Vocabulario de esta práctica
> - **Firmar un commit:** añadir una firma que permite comprobar que se utilizó una clave privada concreta.
> - **"Verified":** el badge que GitHub muestra cuando puede validar la firma y asociar el commit a una identidad reconocida.
> - **Signing Key:** clave añadida en GitHub con el rol de firma.

> [!note] Requisitos antes de empezar
> Necesitas Git 2.34 o posterior y un correo de autoría vinculado a tu cuenta GitHub o su dirección noreply. En el Paso 1 comprobarás ambos requisitos, antes de configurar la firma.
>
> Si en `EJ-01-01-05` elegiste conectar por SSH, puede que ya tengas `id_ed25519`. Comprueba si el archivo existe antes de generar otra clave; nunca sobrescribas una clave que ya uses.

> [!example] Paso 1 — Comprueba versión, correo y existencia de clave
> Revisa Git y el correo configurado. El correo debe estar vinculado a tu cuenta GitHub o ser la dirección noreply que GitHub te proporciona.
> ```
> git --version
> git config user.email
> ```
> **Línea por línea:**
> 1. `git --version`: Confirma que tienes Git 2.34 o posterior, necesario para la firma SSH.
> 2. `git config user.email`: Muestra el correo de autoría. Si no es un correo vinculado o noreply de tu cuenta, consulta en GitHub cuál debes usar y configúralo solo en este repositorio antes de seguir:
>
> Si la versión es anterior a Git 2.34, detente y consulta al profesor antes de continuar. Comprueba ahora si ya existe la clave privada. Ejecuta solo el comando de tu terminal:
> *🐧 Git Bash / Linux*
> ```bash
> ls ~/.ssh/id_ed25519
> ```
> *🪟 PowerShell*
> ```powershell
> Test-Path "$env:USERPROFILE\.ssh\id_ed25519"
> ```
> **Línea por línea:**
> 1. `ls ~/.ssh/id_ed25519`: Muestra la clave si existe; si indica que no la encuentra, no tienes esa clave en la ruta habitual.
> 2. `Test-Path ...`: Devuelve `True` si existe la clave en la ruta habitual de Windows y `False` si no.
>
> Si el correo mostrado no corresponde a tu cuenta, primero abre una terminal en `Manuales/` y fija aquí la dirección que GitHub te indica:
> ```
> git config --local user.email "CORREO_VINCULADO_O_NOREPLY"
> git config user.email
> ```
> **Línea por línea:**
> 1. `git config --local user.email ...`: Configura la dirección solo para este repositorio. Sustituye el texto de ejemplo por la dirección exacta que aparece en GitHub.
> 2. `git config user.email`: Comprueba que quedó guardada.
>
> Solo si el archivo **no existe**, genera una clave nueva:
> ```
> ssh-keygen -t ed25519 -C "correo-vinculado-a-tu-cuenta-GitHub"
> ```
> **Línea por línea:**
> 1. `ssh-keygen -t ed25519 ...`: Genera la nueva clave únicamente si no había una clave en la ruta habitual.
> Acepta la ruta por defecto. Elige una passphrase que puedas guardar de forma segura; no la muestres en el vídeo final. Si el archivo ya existe, no ejecutes `ssh-keygen` ni lo sobrescribas: utiliza esa clave.

> [!example] Paso 2 — Muestra tu clave pública
> *🐧 Git Bash / Linux*
> ```bash
> cat ~/.ssh/id_ed25519.pub
> ```
> **Línea por línea:**
> 1. `cat ~/.ssh/id_ed25519.pub`: Muestra la clave pública, que termina en `.pub` y puede añadirse a GitHub.
> *🪟 PowerShell*
> ```powershell
> cat $env:USERPROFILE\.ssh\id_ed25519.pub
> ```
> **Línea por línea:**
> 1. `cat $env:USERPROFILE\.ssh\id_ed25519.pub`: Muestra la clave pública desde la carpeta de usuario en PowerShell.

> [!example] Paso 3 — Añádela a GitHub como clave de firma
> Copia el contenido. En GitHub: **Settings → SSH and GPG keys → New SSH key**. En **Key type**, elige **"Signing Key"**. Pega y guarda.
> *(Si ya la añadiste como "Authentication Key", añádela otra vez ahora como "Signing Key": la misma clave sirve para las dos cosas.)*

> [!example] Paso 4 — Configura Git para firmar con SSH
> *🐧 Git Bash / Linux*
> ```bash
> git config --local gpg.format ssh
> git config --local user.signingkey ~/.ssh/id_ed25519.pub
> git config --local commit.gpgsign true
> ```
> **Línea por línea:**
> 1. `git config --local gpg.format ssh`: Indica a este repositorio que utilizará firmas SSH.
> 2. `git config --local user.signingkey ~/.ssh/id_ed25519.pub`: Indica la clave pública cuya pareja privada firmará los commits.
> 3. `git config --local commit.gpgsign true`: Activa la firma automática solo en este repositorio.
> *🪟 PowerShell*
> ```powershell
> git config --local gpg.format ssh
> git config --local user.signingkey $env:USERPROFILE\.ssh\id_ed25519.pub
> git config --local commit.gpgsign true
> ```
> **Línea por línea:**
> 1. `git config --local gpg.format ssh`: Indica a este repositorio que utilizará firmas SSH.
> 2. `git config --local user.signingkey $env:USERPROFILE\.ssh\id_ed25519.pub`: Indica la clave pública cuya pareja privada firmará los commits.
> 3. `git config --local commit.gpgsign true`: Activa la firma automática solo en este repositorio.
