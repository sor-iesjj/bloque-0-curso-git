## EJ-01-01-01 — Marko instala Git por primera vez

> [!info] Situación

- **🎯 Objetivo real:** tener Git operativo y verificarlo desde la terminal. Sin esto, ningún ejercicio posterior funciona.
- **🧩 Problema que resuelve:** sin Git instalado, Marko no puede versionar nada, ni colaborar, ni subir a GitHub. Está aislado.

---

## 📚 Fundamento

> [!info] Antes de empezar: ¿qué es Git?
> Git es una herramienta de **control de versiones**: registra la evolución de una carpeta de trabajo (qué archivos cambian, cuándo y quién). **No** es una nube ni una copia de seguridad automática: trabaja primero en local, en tu propio equipo. Más adelante lo conectaremos con GitHub para enviar esos cambios a internet.

> [!tip] Idea clave
> Piensa en Git como la **caja negra de un avión**, pero para tus archivos: si algo sale mal, permite revisar qué pasó y volver a puntos anteriores. En este primer ejercicio solo lo instalas y compruebas que la terminal puede ejecutarlo.

> [!example] Vocabulario de esta práctica
> - **Git:** programa que registra cambios en archivos.
> - **Terminal:** ventana para escribir comandos. En Windows tienes **PowerShell** y **Git Bash** (se instala con Git, usa comandos tipo Linux). En Linux, la app **Terminal**.
> - **`git --version`:** comando que muestra qué edición de Git tienes.

---

## 🛠️ Procedimiento

> [!example] Paso 1 — Descarga Git
> En el navegador, entra en `https://git-scm.com/download/win` y descarga el instalador de 64 bits.

> [!example] Paso 2 — Instálalo
> Ejecuta el instalador y acepta TODOS los valores por defecto **excepto** la pantalla "Default editor": elige **Visual Studio Code** (o Notepad++ si no tienes VS Code).

> [!example] Paso 3 — Abre una terminal
> Tienes dos, y `git --version` funciona en las dos:
> - **🪟 PowerShell** — Win + R → `powershell` → Enter.
> - **🐧 Git Bash** — busca "Git Bash" en el menú de inicio (se instaló junto con Git). La usaremos más adelante para las claves SSH.

> [!example] Paso 4 — Verifica la instalación
> ```
> git --version
> ```
> Debe aparecer algo como `git version 2.43.0.windows.1`.

## 🚩 Errores y verificación

> [!warning] Errores típicos (evítalos)
> | Error | Qué pasa | Cómo evitarlo |
> | :--- | :--- | :--- |
> | "git no se reconoce como comando" | La terminal no encuentra Git | Cierra y abre la terminal; si sigue, reinicia Windows. |
> | Versión muy antigua (< 2.40) | Faltan funciones que usaremos | Reinstala desde la web oficial. |
