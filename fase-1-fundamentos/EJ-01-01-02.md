## EJ-01-01-02 — Marko se identifica ante Git

> [!info] Situación
> Marko ya tiene Git instalado. Antes de hacer cualquier commit, Git necesita saber **quién es Marko** para firmar cada cambio. Si no se identifica, los commits aparecerán como "anónimo" o directamente fallará.

- **🎯 Objetivo real:** configurar la identidad global (nombre + email) para que cada commit quede firmado y sea trazable.
- **🧩 Problema que resuelve:** sin identidad, Carlos no puede saber quién escribió cada cambio. La auditoría desaparece.

---

## 📚 Fundamento

> [!info] Antes de empezar: Git necesita saber quién eres
> Cada commit guarda información de autoría: **nombre, correo, fecha y mensaje**. No es decorativo: en un equipo real permite saber quién modificó un manual, cuándo, y a quién preguntar si algo falla.

> [!tip] Identidad de Git ≠ cuenta de GitHub
> Aquí configuras tu **identidad local de Git** (lo que firma tus commits en tu ordenador). **GitHub** es otra cosa (la web donde publicarás). Conviene que el correo coincida en ambos, pero ahora solo tocamos Git en local.

> [!example] Vocabulario de esta práctica
> - **`user.name` / `user.email`:** tu identidad para firmar commits.
> - **`--global`:** vale para **todos** los repositorios de tu usuario (no "para internet").
> - **Trazabilidad:** poder saber quién hizo cada cambio.

---

## 🛠️ Procedimiento
Los comandos `git config` son **idénticos en PowerShell y en Git Bash**.

> [!example] Paso 1 — Configura tu nombre
> ```
> git config --global user.name "Marko Boochan"
> ```

> [!example] Paso 2 — Configura tu correo (el mismo que usarás en GitHub)
> ```
> git config --global user.email "marko@boochan.local"
> ```

> [!example] Paso 3 — Verifica que se guardó
> ```
> git config --list
> ```
> Busca las líneas `user.name=...` y `user.email=...`.

---

## 🚩 Errores y verificación

> [!warning] Errores típicos (evítalos)
> | Error | Qué pasa | Cómo evitarlo |
> | :--- | :--- | :--- |
> | Confundes `--global` con "para internet" | Malentendido | `--global` = para todos TUS repos de este usuario. |
> | Escribes mal el nombre o correo | Los commits salen con identidad incorrecta | Revísalo con `git config --list` y corrige. |

> [!success] ✅ Verificación: ¿está bien hecho?
> - `git config user.name` devuelve "Marko Boochan".
> - `git config user.email` devuelve "marko@boochan.local".
