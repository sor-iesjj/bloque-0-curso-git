> [!info] Situación
> Marko lleva una semana tecleando `git status` 50 veces al día. Carlos le dice: *"Yo escribo `git st`. Tú también puedes."*

- **🎯 Objetivo real:** configurar **alias** de Git globales para acelerar el trabajo diario.
- **🧩 Problema que resuelve:** repetir comandos largos cansa y ralentiza. Un técnico pasa horas en la terminal: cada segundo cuenta.

---

## 📚 Fundamento

> [!info] Antes de empezar: un alias es un apodo para un comando
> Un **alias** es un nombre corto que tú inventas para un comando largo. Cuando defines `st` como alias de `status`, escribir `git st` es exactamente lo mismo que escribir `git status`, pero más rápido.

> [!abstract] Idea clave: personaliza tu herramienta, sin cambiarla
> Los alias son **tuyos** (se guardan en tu configuración global). No cambian Git ni afectan a tus compañeros: cada técnico puede tener los suyos. Es como poner accesos directos en tu escritorio.

> [!example] Vocabulario de esta práctica
> - **Alias:** apodo corto para un comando.
> - **`--global`:** el alias vale para todos tus repositorios.
> - **Comillas:** si el valor del alias lleva espacios, va entre comillas.

> [!warning] Antes de crear alias globales: comprueba que no vas a reemplazar los tuyos

Si aparece alguno de `st`, `co`, `br`, `lg` o `unstage`, no ejecutes el bloque siguiente: conserva tu alias y consulta al profesor para elegir otro nombre.

> ```bash
> git config --global --get-regexp '^alias\.'
> ```

> [!example] Paso 1 — Crea 5 alias útiles

> git config --global alias.st status

> git config --global alias.unstage "restore --staged"
> ```
