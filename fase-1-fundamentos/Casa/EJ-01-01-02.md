## EJ-01-01-02 — Casa: comprobar tu identidad de Git

> [!important] Esta guía es autónoma para el contexto Casa
> Comprueba la configuración en el ordenador de Casa. No depende de lo que hayas configurado en Cole ni cambia ninguna preferencia. No abras ni cambies carpetas de `SOR` o `Boveda_SOR` para esta consulta; el trabajo posterior se crea en el espacio neutral correspondiente.

> [!danger] No configures la identidad ficticia de Marko
> La identidad global debe ser la tuya. Esta ficha solo consulta valores; **no ejecutes aquí comandos `git config --global` que escriban datos**. Si está vacía o no coincide, no la cambies aquí: esta guía es de consulta. El EJ-01-01-00 configura la identidad real localmente en cada repositorio antes del primer commit.

> [!example] Consulta la identidad global
> Ejecuta las dos consultas:
> ```bash
> git config --global user.name
> git config --global user.email
> ```
> **Línea por línea:** el primer comando consulta el nombre global de Git; el segundo consulta el correo global. Ambos son de solo lectura.
>
> Anota lo que aparece en la entrada del EJ-01-01-00 de este contexto. Si no aparece nada, o ves valores antiguos, continúa solo con la configuración local que establece el EJ-01-01-00 antes de crear commits. No uses `Marko Boochan` ni `marko@boochan.local`. Para asociar commits a GitHub, usa allí un correo verificado o la dirección `noreply` indicada en `Settings → Emails`.

> [!info] Entrega
> No se entrega esta comprobación por separado. La guía del `EJ-01-01-00` de Casa crea su propia bóveda y bitácora desde cero.
