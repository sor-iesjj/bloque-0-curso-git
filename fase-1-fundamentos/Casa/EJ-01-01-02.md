## Guarda la entrada en tu Bitácora

Abre Git Bash/Terminal **dentro de `Bitacora` de Casa**. Primero comprueba dónde estás:

```bash
pwd
```

**Línea 1:** muestra la carpeta actual. Debe terminar exactamente en `/SOR_Git_Casa/Boveda_Git_Casa/Bitacora`, fuera de las carpetas de apuntes `SOR` y `Boveda_SOR`. Si no coincide o tienes dudas, **detente antes del siguiente bloque** y vuelve a abrir la terminal en la carpeta correcta.

Comprueba ahora el repositorio antes de preparar cambios:

```bash
git remote -v
git status
```

- **Línea 1:** debe mostrar tu remoto `bitacora-curso-git-casa`, nunca el del profesor ni el del otro contexto.
- **Línea 2:** muestra qué archivos han cambiado. Guarda la entrada en Obsidian; debe aparecer `git-1.1.2-comprueba-identidad-de-git-casa.md`. Si hay archivos de otro trabajo preparados o el remoto no coincide, detente y pide ayuda.

Prepara solo esta entrada y revisa lo que vas a guardar:

```bash
git add git-1.1.2-comprueba-identidad-de-git-casa.md
git diff --cached --stat
```

- **Línea 1:** prepara la entrada de esta práctica.
- **Línea 2:** muestra los archivos preparados. Debe aparecer solo `git-1.1.2-comprueba-identidad-de-git-casa.md`. Si la lista no coincide, **no ejecutes el siguiente bloque**; consulta al profesor.

Guarda la entrada en el historial local:

```bash
git commit -m "Casa: EJ-01-01-02 documentado"
```

**Línea 1:** crea el commit. Si muestra un error, detente y resuélvelo antes de subir.

Envía el commit a tu Bitácora de GitHub:

```bash
git push
```

**Línea 1:** envía los commits a tu remoto. Abre ese repositorio en GitHub y comprueba que la entrada aparece con su contenido.
