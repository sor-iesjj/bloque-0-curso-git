## EJ-01-01-01 — Casa: comprobar Git en este equipo

> [!important] Esta guía es autónoma para el contexto Casa
> Sigue esta comprobación en el ordenador de Casa, aunque ya hayas trabajado en el otro entorno. No supongas que Git está instalado aquí ni que una captura del otro equipo sirve como evidencia.

> [!example] Comprueba si Git está instalado
> Abre Git Bash o PowerShell en Windows, o Terminal en Linux, y ejecuta:
> ```bash
> git --version
> ```
> Si aparece una versión de Git, anótala para la entrada del `EJ-01-01-00` de Casa. Si `git --version` dice `command not found`, detente. En Casa, sigue [Bloque 0 · Fase 0.5.1](../../../01_Prerrequisitos/Fase_0.5.1_Montar_Entorno_Casa.md) hasta el apartado de instalación (te remite a la nota de Fase 0.2.1), cierra y reabre Git Bash y repite la comprobación. En Cole, avisa al profesor. Continúa solo cuando aparezca una versión.

> [!info] Entrega
> Esta comprobación se registra en la entrada única de `EJ-01-01-00` para Casa. No lleva entrada ni vídeo separados. A continuación, abre [`EJ-01-01-02`](EJ-01-01-02.md) de esta misma carpeta y después [`EJ-01-01-00`](EJ-01-01-00.md).
