## EJ-01-03-04 — Marko firma sus commits para garantizar autoría

> [!abstract] Ficha de la práctica
> ### 📌 `F1.3.4` — Marko firma sus commits para garantizar autoría
> - **Fase 1** (Fundamentos) · **Nivel 3** (Sobresaliente)
> - **🎬 Playlist:** `Curso Git — Fase 1`
> - **📹 Nombre del vídeo:** `F1.3.4 · Marko firma sus commits para garantizar autoría`

> [!info] Situación
> Lucía le pide a Marko: *"En cuanto hagas algo crítico (cambio de seguridad, configuración de firewall), quiero poder verificar criptográficamente que el commit es tuyo y que nadie ha suplantado tu identidad."*

- **🎯 Objetivo real:** configurar la **firma de commits con clave SSH** (más simple que GPG en Windows). Cada commit firmado aparece como **"Verified"** en GitHub.
- **🧩 Problema que resuelve:** sin firma, cualquiera puede commitear poniendo `user.name = Marko Boochan` desde otro PC. La firma es **prueba criptográfica** de autoría.

---

## 📚 Fundamento

> [!info] Antes de empezar: nombre ≠ prueba
> En el EJ-01-01-02 configuraste tu nombre y correo. Pero eso es solo una **etiqueta**: cualquiera puede escribir tu nombre. **Firmar** un commit con tu clave privada es distinto: es una **prueba matemática** de que fuiste tú, imposible de falsificar sin tu clave.

> [!abstract] Idea clave: la misma clave SSH sirve para dos cosas
> La clave SSH que usas para **conectar** con GitHub puede usarse también para **firmar** commits. Solo hay que añadirla en GitHub una segunda vez, marcándola como "Signing Key".

> [!example] Vocabulario de esta práctica
> - **Firmar un commit:** añadirle una prueba criptográfica de autoría.
> - **"Verified":** el badge verde que GitHub muestra en un commit firmado y válido.
> - **Signing Key:** clave añadida en GitHub con el rol de firma.

> [!note] Puede que ya tengas la clave
> Si en el EJ-01-01-05 elegiste conectar por **SSH**, ya generaste `id_ed25519`. En ese caso, salta el Paso 1 y reutilízala.

## 🛠️ Procedimiento

> [!example] Paso 0 — Prepárate y empieza a grabar
> 1. **Léete el ejercicio entero** antes de tocar nada, para no perderte a mitad del vídeo.
> 2. **Ten a mano OBS** y una pestaña del navegador con tu **Teams** o tu correo `@alu.edu.gva.es` (para presentarte).
> 3. **Arranca OBS** y pulsa **"Iniciar grabación"**. A partir de aquí, **todo queda grabado**.
> 4. **Preséntate** (mira la caja de grabación de arriba): di tu nombre, muestra tu identidad y di qué vas a hacer.

> [!example] Paso 1 — Genera la clave SSH (si no la tienes)
> El comando `ssh-keygen` es igual en las dos terminales:
> ```
> ssh-keygen -t ed25519 -C "marko@boochan.local"
> ```
> Acepta la ruta por defecto. Sin passphrase, para simplificar.

> [!example] Paso 2 — Muestra tu clave pública
> *🐧 Git Bash / Linux*
> ```bash
> cat ~/.ssh/id_ed25519.pub
> ```
> *🪟 PowerShell*
> ```powershell
> cat $env:USERPROFILE\.ssh\id_ed25519.pub
> ```

> [!example] Paso 3 — Añádela a GitHub como clave de firma
> Copia el contenido. En GitHub: **Settings → SSH and GPG keys → New SSH key**. En **Key type**, elige **"Signing Key"**. Pega y guarda.
> *(Si ya la añadiste como "Authentication Key", añádela otra vez ahora como "Signing Key": la misma clave sirve para las dos cosas.)*

> [!example] Paso 4 — Configura Git para firmar con SSH
> *🐧 Git Bash / Linux*
> ```bash
> git config --global gpg.format ssh
> git config --global user.signingkey ~/.ssh/id_ed25519.pub
> git config --global commit.gpgsign true
> ```
> *🪟 PowerShell*
> ```powershell
> git config --global gpg.format ssh
> git config --global user.signingkey $env:USERPROFILE\.ssh\id_ed25519.pub
> git config --global commit.gpgsign true
> ```

> [!example] Paso 5 — Haz un commit firmado y súbelo
> Dentro de `Manuales/`, edita algo (p. ej. el índice) y:
> ```
> git add .
> git commit -m "EJ-01-03-04 · Primer commit firmado con SSH"
> git push
> ```

> [!example] Paso 6 — Compruébalo en GitHub
> Abre el commit en GitHub: debe aparecer el badge verde **"Verified"**.

> [!example] Paso 7 — Cierra la grabación y súbela
> 1. **Detén la grabación** en OBS y localiza el archivo del vídeo.
> 2. **Súbelo a YouTube**, a tu playlist **`Curso Git — Fase 1`**, como **"No listado"**.

## 🚩 Errores y verificación

> [!warning] Errores típicos (evítalos)
> | Error | Qué pasa | Cómo evitarlo |
> | :--- | :--- | :--- |
> | El badge sale gris ("Unverified") | La clave no está como "Signing key" | Revísala en GitHub: debe estar añadida con tipo **Signing Key**. |
> | Confundes firmar con conectar | Son usos distintos de la misma clave | Puedes añadir la misma clave para autenticación **y** para firma. |
