## EJ-05-01-03 — Marko automatiza un sync nocturno con un script

> [!abstract] Ficha de la práctica
> ### 📌 `F5.1.3` — Marko automatiza un sync nocturno con un script
> - **Fase 5** (Integración) · **Nivel 1** (Mínimo)
> - **🎬 Playlist:** `Curso Git — Fase 5`
> - **📹 Nombre del vídeo:** `F5.1.3 · Marko automatiza un sync nocturno con un script`

> [!info] Situación
> Marko quiere que cada noche, sin hacer nada, su repositorio se sincronice con GitHub: commit automático de lo que haya cambiado + push.

- **🎯 Objetivo real:** crear un **script** de sincronización y **programarlo** para que se ejecute solo.
- **🧩 Problema que resuelve:** si Marko olvida pushear, los cambios quedan solo en local; si se rompe el portátil, se pierden.

---

## 📚 Fundamento

> [!info] Antes de empezar: automatizar una rutina
> Un **script** es un archivo con una lista de comandos que se ejecutan de golpe. Si además lo **programas** (Programador de tareas en Windows, `cron` en Linux), se lanza **solo** a la hora que digas. Aquí automatizamos el "guardar y subir" de cada noche.

> [!warning] Ojo: esto es para el repo, no para toda la bóveda
> El script sincroniza el repositorio `Manuales/` (que sí es un repo). La **bóveda contenedor** no se versiona, así que el script apunta **dentro** de `Manuales/`.

> [!example] Vocabulario de esta práctica
> - **Script:** archivo con comandos que se ejecutan juntos.
> - **Programador de tareas / `cron`:** lanza el script a una hora fija.
> - **`2>$null`:** silencia los errores (por ejemplo, si no hay nada que commitear).

## 🛠️ Procedimiento

> [!example] Paso 0 — Prepárate y empieza a grabar
> 1. **Léete el ejercicio entero** antes de tocar nada, para no perderte a mitad del vídeo.
> 2. **Ten a mano OBS** y una pestaña del navegador con tu **Teams** o tu correo `@alu.edu.gva.es` (para presentarte).
> 3. **Arranca OBS** y pulsa **"Iniciar grabación"**. A partir de aquí, **todo queda grabado**.
> 4. **Preséntate** (mira la caja de grabación de arriba): di tu nombre, muestra tu identidad y di qué vas a hacer.

> [!example] Paso 1 — Crea el script
> *🪟 PowerShell* — `Manuales\scripts\sync-nocturno.ps1`:
> ```powershell
> Set-Location -Path "$env:USERPROFILE\Boveda_Marko\Manuales"
> git add .
> $fecha = Get-Date -Format "yyyy-MM-dd HH:mm"
> git commit -m "Auto-sync nocturno · $fecha" 2>$null
> git push 2>$null
> ```
> *🐧 Linux (equivalente)* — `Manuales/scripts/sync-nocturno.sh`:
> ```bash
> #!/bin/sh
> cd ~/Boveda_Marko/Manuales || exit
> git add .
> git commit -m "Auto-sync nocturno · $(date '+%Y-%m-%d %H:%M')" 2>/dev/null
> git push 2>/dev/null
> ```

> [!example] Paso 2 — Pruébalo a mano
> *🪟 PowerShell*
> ```powershell
> powershell -File scripts\sync-nocturno.ps1
> ```
> *🐧 Linux*
> ```bash
> sh scripts/sync-nocturno.sh
> ```

> [!example] Paso 3 — Prográmalo para cada noche
> *🪟 Windows:* Win + R → `taskschd.msc` → **Create Basic Task** → Trigger **Daily 23:00** → Action **Start a program** → `powershell.exe` con Arguments `-File "C:\Users\...\Boveda_Marko\Manuales\scripts\sync-nocturno.ps1"`.
> *🐧 Linux:* `crontab -e` y añade: `0 23 * * * sh ~/Boveda_Marko/Manuales/scripts/sync-nocturno.sh`

> [!example] Paso 4 — Verifica al día siguiente
> Comprueba que aparece un commit automático "Auto-sync nocturno · ...".
