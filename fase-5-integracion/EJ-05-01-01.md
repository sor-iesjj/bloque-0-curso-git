## EJ-05-01-01 — Marko usa GitHub Desktop como alternativa visual

> [!info] Situación
> Marko forma a alumnos junior; algunos se atascan con la terminal. Lucía: *"Para ellos, instala GitHub Desktop. La interfaz visual ayuda a entender."*

- **🎯 Objetivo real:** conocer **GitHub Desktop** como alternativa visual a la línea de comandos para tareas básicas.
- **🧩 Problema que resuelve:** no todos entienden la terminal; una interfaz visual baja la barrera de entrada.

---

## 📚 Fundamento

> [!info] Antes de empezar: la misma Git, otra cara
> GitHub Desktop es un **programa con ventanas** que hace por debajo lo mismo que la terminal: ver cambios, commitear, hacer push/pull. No es "otra cosa": es **Git con botones**. Ver el diff de forma visual ayuda mucho a entender qué está pasando.

> [!abstract] Idea clave: visual para lo básico, terminal para lo potente
> Para lo del día a día (commit, push, cambiar de rama), la interfaz va de sobra. Para lo avanzado (rebase, cherry-pick, worktree), la **terminal** sigue siendo el sitio. Un buen técnico usa las dos según convenga.

> [!example] Vocabulario de esta práctica
> - **GitHub Desktop:** cliente gráfico de Git/GitHub.
> - **Diff visual:** ver los cambios resaltados en ventana.

---

## 🛠️ Procedimiento

> [!example] Paso 1 — Instálalo e inicia sesión
> Descarga de `https://desktop.github.com/`, instálalo y entra con tu cuenta de GitHub.

> [!example] Paso 2 — Añade tu repositorio
> **"Add an Existing Repository"** → selecciona la carpeta de tu clon de **`manuales-boochan`**.

> [!example] Paso 3 — Haz un cambio y míralo
> Edita cualquier archivo (con Obsidian o VS Code) y vuelve a GitHub Desktop: verás el **diff visual**.

> [!example] Paso 4 — Commit y push desde la interfaz
> Escribe el mensaje `EJ-05-01-01 · Probado GitHub Desktop`, pulsa **"Commit to develop"** y luego **"Push origin"**.

## 🚩 Errores y verificación

> [!warning] Errores típicos (evítalos)
> | Error | Qué pasa | Cómo evitarlo |
> | :--- | :--- | :--- |
> | Esperas hacer rebase/cherry-pick aquí | La interfaz no cubre todo | Para lo avanzado, usa la terminal. |
> | Commiteas en la rama equivocada | El desplegable indica la rama | Comprueba la rama antes de commitear. |

> [!success] ✅ Verificación: ¿está bien hecho?
> - El commit hecho desde GitHub Desktop es visible en GitHub.
