## EJ-05-02-03 — Marko usa GitHub CLI (`gh`) desde la terminal

> [!abstract] Ficha de la práctica
> ### 📌 `B0.G.5.2.3` — Marko usa GitHub CLI (`gh`) para todo desde terminal
> - **Fase 5** (Integración) · **Nivel 2** (Notable)
> - **🎬 Playlist:** `B0_Curso_Git`
> - **📹 Nombre del vídeo:** `B0.G.5.2.3 · Marko usa GitHub CLI (gh) para todo desde terminal`

> [!info] Situación
> Marko se cansa de saltar al navegador para abrir PRs, ver checks o listar issues. Instala **`gh`** para hacerlo todo desde la terminal.

- **🎯 Objetivo real:** manejar PRs, issues, checks y workflows con **`gh`** sin tocar el navegador.
- **🧩 Problema que resuelve:** cambiar de contexto (terminal → navegador → terminal) rompe el ritmo.

---

## 📚 Fundamento

> [!info] Antes de empezar: GitHub, pero en la terminal
> **`gh`** es la herramienta oficial de GitHub para la línea de comandos. Lo que harías con el ratón en la web (abrir un PR, revisarlo, fusionarlo, ver Actions) lo haces con comandos. Ideal cuando ya vives en la terminal.

> [!abstract] Idea clave: menos saltos = más foco
> No es que la web esté mal; es que **cambiar de ventana** todo el rato cansa. Con `gh`, mantienes el foco en un solo sitio y trabajas más rápido.

> [!example] Vocabulario de esta práctica
> - **`gh`:** cliente oficial de GitHub para la terminal.
> - **`gh auth login`:** conecta `gh` con tu cuenta.
> - **`gh pr` / `gh issue` / `gh run`:** familias de comandos para PRs, issues y Actions.

> ```

> [!example] Paso 3 — Prueba los comandos más útiles
> ```
> gh repo view --web              # abre el repo en el navegador
> gh pr list                      # lista PRs
> gh pr create --title "..." --body "..." --base develop
> gh pr checkout 5                # descarga la rama del PR 5
> gh pr merge 5 --squash --delete-branch
> gh issue list
> gh issue create -t "..." -b "..."
> gh run list                     # ejecuciones de Actions
> gh run watch                    # sigue una ejecución en vivo
> ```

## 🚩 Errores y verificación

> [!warning] Errores típicos (evítalos)
> | Error | Qué pasa | Cómo evitarlo |
> | :--- | :--- | :--- |
> | Usas `gh` sin `gh auth login` | Comandos fallan por falta de permiso | Inicia sesión una vez con `gh auth login`. |
> | Confundes `gh` con `git` | Son cosas distintas | `git` gestiona el repo local; `gh` habla con GitHub. |
